# 飞冬机团队（Feidongji）

> **飞冬机团队（Feidongji）** 是一个围绕互联网技术、编程与游戏开展项目的团队，成立于 2025 年。

**Feidongji 是“飞冬机团队”的英文名称。**  
“飞冬机团队”和“Feidongji”指向同一团队，并非两个不同组织。

[官方网站](https://main.feidongji.com/) · [GitHub 公开主页](https://github.com/feiji-ks)

## 关于

飞冬机团队（Feidongji）目前主要围绕互联网技术、编程与游戏开展公开项目。

目前主要方向包括：

- Minecraft 服务器
- Minecraft 整合包设计
- 网站与 Web 项目
- 软件与自动化项目

未来项目方向会根据团队实际发展逐步扩展。
