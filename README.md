# 飞冬机团队

## 关于

飞冬机团队（Feidongji）目前主要围绕互联网技术、编程与游戏开展公开项目。

目前主要方向包括（按照权重排名）：

- 我的世界(java) 材质包
- 我的世界(java) 新手指导
- 部分摸金游戏的陪玩/陪练
- 网站与 Web 项目

未来项目方向会根据团队实际发展逐步扩展。
