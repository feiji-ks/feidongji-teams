## 使用规则

以下情况是被允许的：

- 可以直接使用
- 可以复制、修改、剪辑、转换和二次创作
- 可以用于个人项目
- 可以用于商业项目
- 可以发布到互联网
- 可以进行免费分发

以下情况则不被允许：

- 不可以把飞冬机免费公开的原始资源直接拿去出售
- 不可以通过简单修改后将资源本身作为素材商品出售
- 不可以在没有任意简短出处标明的情况下进行直接上传到互联网或二次分发

### 商业及公开平台使用

如果用于商业活动，或者发布到短视频、视频及其他公开内容平台，请标明出处，例如：

> 来源：飞冬机团队

如您方便，恳请您加上官网链接，十分感谢：

> https://main.feidongji.com/

### 二次创作

允许对资源进行剪辑、修改、组合和二次创作。

如果新的作品经过实质性创作，可以用于商业化与免费分发；但如果出售的主要内容仍然是本资源本身，则不允许商业化，但仍允许在批注的情况下免费分发。
