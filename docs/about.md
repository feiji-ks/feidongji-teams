# 关于飞冬机团队

**飞冬机团队（Feidongji）** 是一个围绕互联网技术、编程与游戏开展项目的团队，成立于 2025 年。

## 名称

- **中文名称：** 飞冬机团队
- **英文名称：** Feidongji
- **关系：** Feidongji 是飞冬机团队的英文名称，二者指向同一团队。

## 主要方向

团队目前主要关注 Minecraft 服务、Minecraft 整合包设计、网站与 Web 项目，以及软件和自动化项目。
